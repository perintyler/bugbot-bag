# Bugbot (Barry bag)

Cursor Bugbot PR-review workflow — clean up, triage, and babysit bugbot findings.

## Tools

- `fetch_unresolved_comments` — fetch unresolved Cursor Bugbot review threads on a GitHub PR

## Skills

- `bugbot-triage` — fetch unresolved bugbot comments on a PR, investigate each finding, and propose resolutions with confidence scores
- `bugbot-clean` — delete all Cursor Bugbot comments on a PR and hide review summaries
- `bugbot-babysit` — babysit a PR's bugbot review cycle until every finding is resolved
